# How to play
- Press Esc to set / reset table.
- Click and drag cue to charge shot, release to shoot.
- Cancel shot by dragging cue back to center and releasing.
- If cue ball is pocketed, place it back on the table anywhere by clicking.
- Press ~ to toggle debug overlay.

# Details
A fast physics loop and a sub tick collision resolution allows for a reasonably accurate sim.\
You'll probably need to zoom out. I've never heard the term "responsive design".\
Debug overlay shows velocity vectors for balls, and wall normals.
